# WildVision

WildVision 是一个给动物视频做行为标注的桌面工具。选中动物和行为，在视频中标出开始、结束时间，就能保存并导出标注结果。

## 下载和打开

到 [Releases](https://github.com/AImiHoYo/WildVision/releases) 下载对应的 ZIP 附件，**完整解压后再打开程序**：

- **Apple 芯片的 Mac（M 系列）**：选文件名带 `macOS-arm64` 的 ZIP，双击文件夹中的 `WildVision.app`。
- **Intel / AMD 64 位 Windows**：选文件名带 `Windows-x64` 的 ZIP，双击文件夹中的 `WildVision.exe`。

不需要自己安装 Python、FFmpeg 或配置开发环境。Windows 首次启动若提示安装 WebView2，按提示完成即可。不要下载页面底部的 `Source code` 来运行软件，那是给开发者用的源码。当前没有 Intel Mac 安装包；ZIP 旁的 `.sha256` 文件供核对下载是否完整。

请保留整个解压文件夹，把它放在“文稿”或个人工作目录等可写入的位置。程序旁的 `datasets` 用来存导入的视频和标注，不要只把 `.app` 或 `.exe` 单独搬走。

### 如果出现“选择软件所在文件夹”

点击“选择软件文件夹”，选中**刚解压的整个 WildVision 文件夹**。进入这个文件夹，应能直接看到 `WildVision.app` 或 `WildVision.exe`。

这一步是在确认软件和数据的保存位置。**不要选数据集 ZIP、`datasets` 子文件夹或 App 内部目录**。确认后会进入样本库，再按下面的步骤导入数据集。选错了会显示红色原因提示，点“重新选择软件文件夹”重试即可，不需要移动 App 或打开终端。

默认会记住软件位置。文件夹被移动、无法写入或已记住的位置失效时，软件会再次引导选择；原有数据不会自动搬走或删除。

### Mac 首次打开提示“Apple 无法验证”

macOS 版采用本地自签名（ad-hoc），没有 Apple Developer ID 签名与公证。第一次打开时，可能出现下面的提示：

![macOS 提示未打开 WildVision.app，Apple 无法验证应用](doc/images/macos-unverified-app.png)

确认 ZIP 来自本仓库后，按下面的步骤打开：

1. 在这个弹窗中点“完成”，保留 `WildVision.app`。
2. 打开“系统设置 → 隐私与安全性”，向下找到“安全性”区域中刚刚阻止 WildVision 的提示。
3. 点“仍要打开”，按系统要求验证身份，并在后续弹窗中确认“打开”。
4. 之后从保留的便携文件夹中打开 WildVision，不要单独移动 `.app`。

如果还没有出现“仍要打开”，先再尝试打开一次 WildVision，再回到“隐私与安全性”查看。[Apple 官方操作说明](https://support.apple.com/zh-cn/102445)。

## 跟着做一次视频标注

下面是在 **macOS 版 WildVision v1.1.3** 中实际操作的截图，使用 `prepared_ak_100.zip` 数据集里的 `AASSQKOU.mp4` 演示。图中的 0–2 秒区间只用来说明操作，不作为已审核的行为真值。Windows 用户可按相同按钮名称操作。

### 1. 导入准备好的数据集

在样本库右上角点“导入 → 导入压缩包”，选择拿到的数据集 ZIP。已经解压的数据集则选“导入文件夹”。

![样本库右上角的导入菜单，包含导入压缩包和导入文件夹](doc/images/guide/ak-00-import.png)

等待导入完成，视频会变成一张张卡片。本例导入了 100 段视频，找到 `AASSQKOU.mp4`，点它右下角的“打开”。你也可以用顶部搜索框找视频编号。

![prepared_ak_100 导入后的样本库，第二张卡片是 AASSQKOU.mp4](doc/images/guide/ak-01-library.png)

标注员拿到准备好的数据集后直接导入即可。数据集需要包含视频，以及预先列好动物和可选行为的 JSON；如果你负责准备数据，见后面的[数据集格式](#数据集格式)。暂时没有数据集时，可用“导入 → 示例数据”练习，内置的是测试图案视频。

### 2. 选行为、选轨道，标出起点

先看视频，确认要标的是哪个对象、哪种行为。在右侧“可选行为”中点击行为，再点击下方时间线对应的动物轨道。**轨道就是放置这组标注的一行**，请按数据集给定的动物和编号使用。

本例选的是 `Sleeping in its nest`，以及 `Yellowhammer Young #1` 轨道。把视频停在起始位置，点播放栏的“标起点”（也可以按 `I`）。按钮变成“起点 00:00.000”，表示已经记下起点，此时还没有生成完整区间。

![选中 Sleeping in its nest 和第一条轨道，已记录 0 秒起点](doc/images/guide/ak-02-start.png)

软件不会自动识别或跟踪动物；同一对象的编号和标注含义需要由标注者保持一致。

### 3. 到结束位置，点“标终点”

播放视频，或拖动播放位置到行为结束处，再点“标终点”（按 `O`）。本例停在 2 秒，生成了 0–2 秒的蓝色时间条，右侧“已标区间”也出现了对应记录。

![已生成 0 到 2 秒的时间条，右侧显示起止时间](doc/images/guide/ak-03-segment.png)

起止位置拿不准时，用播放栏的上一帧、下一帧微调。起点标错了，按 `Esc` 取消后重标。完成一段后继续标下一段；需要换轨道时，先选中对应的一行。

**看得太快，可以调慢播放**。点播放栏中音量右边的 `1×`，选择 `0.25×`、`0.5×`、`1×`、`1.5×`、`2×`、`3×`；也可以输入自定义倍速并点“应用”。切换视频后会保留所选倍速，标注仍按原视频时间记录。

![播放栏倍速菜单，包含六个预设和自定义输入框](doc/images/guide/ak-06-speed.png)

注意：时间线右上角也有 `1x / 2x / 4x`，那是**时间线缩放**，与播放倍速分开使用。

### 4. 检查并修改标注

点选时间条，对照右侧记录检查行为、轨道和起止时间。

- **时间不准**：改右侧的“起”“止”数值，或拖动时间条的两端。
- **行为选错**：右键点这条时间条，在“更换该段行为”的下拉框里选正确的行为。
- **整段不要了**：选中后删除。误删、改错可以点播放栏的撤销按钮恢复。

![右键点击时间条后，菜单中可以更换该段行为](doc/images/guide/ak-04-edit.png)

更换行为会保留这段标注的轨道和时间。即使选中了多段，也只修改右键点击的这一段。如果与同轨道已有的同类行为相接或重叠，软件会提示先调整区间。

### 5. 保存，再切换视频

点右上角“保存”，等按钮显示“已保存”。本例保存后，右侧仍能看到刚才的 0–2 秒区间。

![右上角显示已保存，旁边是上一个和下一个视频按钮](doc/images/guide/ak-05-saved.png)

继续标注时，点顶部“下一个”；要回看则点“上一个”。切换前软件会先保存当前修改，成功后才切换。如果保存失败，或还留着未结束的起点，软件会停在当前视频并提示处理。

下次打开同一数据集，可以继续编辑已保存的结果。**保存写入本地 `datasets`，不会更新当初导入的 ZIP**。要交付给别人，还需要导出。

### 6. 导出要交付的结果

点左上角的数据集名称返回样本库，再点右上角“…”进入“批量选择与导出”。勾选需要交付的视频卡片，确认“已选”数量，再点“导出 (.zip)”，选择保存位置。

![批量选择模式中已勾选 AASSQKOU，右上方可导出 ZIP 或合并 JSON](doc/images/guide/ak-07-export.png)

导出的 ZIP 包含每个视频的标注 JSON、合并 JSON 和配套清单，**不包含原始视频**。也可以直接点“合并 JSON”。本例实际导出的 `annotations/AASSQKOU.json` 保留了 0–2 秒区间。

图中卡片仍显示“进行中 1/12”，因为只演示了一项标注；保存成功不代表整段视频已经标完。正式交付前，请逐项检查需要标注的内容。

只想另存当前视频的 JSON，可用标注界面右上角“…”中的“另存为…”。建议给导出文件注明数据集名称和日期，并另外保留一份备份。

## 常用快捷键

| 操作 | 按键 |
| --- | --- |
| 播放 / 暂停 | 空格 |
| 标起点 / 标终点 | `I` / `O` |
| 取消未完成的起点 | `Esc` |
| 上一帧 / 下一帧 | `←` / `→` |
| 保存 | Windows `Ctrl+S`；Mac `⌘S` |
| 撤销 | Windows `Ctrl+Z`；Mac `⌘Z` |
| 重做 | Windows `Ctrl+Shift+Z`；Mac `⌘Shift+Z` |

输入文字或修改时间数值时，快捷键会让位给输入框。

## 数据在哪里，怎么备份

样本库顶部会显示当前数据目录，点“打开数据文件夹”就能查看。导入时，软件会把数据复制到程序旁的 `datasets`，每个数据集单独放一份：

```text
WildVision-v1.1.3-你的系统与架构/
├── WildVision.app 或 WildVision.exe
├── datasets/
│   └── 你的数据集/
│       ├── videos/         ← 导入的视频
│       └── annotations/    ← 保存的标注 JSON
├── runtime/                ← 自动保存与启动日志
├── core/、desktop/、ui/    ← 随包附带的源码
└── README.md
```

**换电脑或备份时复制整个软件文件夹**。升级时先把新版本解压到另一个文件夹，再将旧版的 `datasets` 和 `runtime` 复制过去；不要用新包里的空目录覆盖已有数据。原始导入 ZIP 和导出结果也建议分别保留。

<details>
<summary>从 v1.1.1 或更早版本迁移数据</summary>

退出旧版，在 Mac 的 Finder 按 `⌘⇧G`，输入 `~/.wildvision/datasets`；Windows 在资源管理器地址栏输入 `%USERPROFILE%\.wildvision\datasets`。把其中的数据集文件夹复制到新版的 `datasets`，保留旧文件。

如果还有旧版自动保存、但未正式保存的修改，请先在旧版里保存，再复制。新版不会自动搬走或删除旧数据。

</details>

## 数据集格式

准备好的数据集通常包含两个文件夹，视频与 JSON 使用相同的文件名：

```text
我的数据集/
├── videos/
│   ├── video01.mp4
│   └── video02.mp4
└── annotations/
    ├── video01.json
    └── video02.json
```

JSON 中需要预先写好动物清单和可选行为，具体字段与示例见[数据格式说明](doc/data_specs/14_AK_Preprocessed_JSON_Schema_and_Guide.md)。可以直接导入这个文件夹，也可以将它压成 ZIP 后导入。

只有单个视频时，可以先“导入 → 添加单个视频”，再从标注界面右上角“…”选择“载入预处理 JSON”。

## 使用前了解这些限制

当前版本适合先用小批数据试用，重要标注请保留导出副本。“行为洞察”中的模型演示使用缓存示例结果，不代表运行了真实模型。新手安装、不同系统的视频声音，以及第三方组件分发材料还有待补齐；具体记录见 [发布状态](doc/release/Release_Readiness_Status.md)、[v1.1.1 倍速验证](doc/release/Playback_Speed_Validation.md) 和 [标注工作流验证](doc/release/Annotation_Workflow_Validation.md)。

遇到问题可在 [Issues](https://github.com/AImiHoYo/WildVision/issues) 留下软件版本、系统和复现步骤。请使用可公开的示例，不要上传私人视频或未经许可的数据。
