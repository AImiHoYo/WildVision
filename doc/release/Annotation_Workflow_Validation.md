2026-10-22。用户授权两个功能完成后发布到公开 GitHub 仓库 `AImiHoYo/WildVision`。本次以预发布状态交付；不将未做的双平台实机检查写成通过。

## 使用方式

- 数据集视频打开后，顶部主题按钮左侧显示“上一个 / 当前位置 / 下一个”。按数据集索引顺序切换；有修改时自动保存，失败留在原视频。到首尾时禁用相应按钮。单独打开、未加入数据集的视频不显示此导航。
- 已标起点但未完成终点时，先完成或取消当前起点，再切换视频，防止丢失未完成标注。
- 右键点击时间线上的某一段，在“更换该段行为”下拉框选择当前动物可用的行为。只改右键点击的这一段，保留动物、轨道、起止时间和段 ID；可撤销/重做，再保存或切换视频。
- 如果同轨道已有相接或重叠的目标行为，会提示先调整区间，不会悄悄合并、删段或扩展时间。

主代理构建前端，原有 11 项前端测试通过；使用合成视频、隔离工作区和真实 Python API，通过本地 HTTP 测试适配器实际操作 React 界面：

1. 首视频上一个按钮禁用，右键菜单只有该动物的 Attending/Eating，不出现 Bird 专用 Flying。

## 新机器重复验证流程

1. 解压目标系统/架构 ZIP，在没有开发环境的用户账户打开应用。导入含至少两个视频、至少两种同动物可用行为的自有/合成数据集。记录版本、系统、架构、包 SHA-256。
2. 打开第一个视频，确认上一个禁用，新增一段，不手动保存，点下一个；确认视频标题、播放时间归零，声音不继续播放旧视频。
3. 返回前一个视频，核对标注内容、时间和已保存状态；再退出重开，确认持久化。末尾下一按钮应禁用，快速双击不能跳两条。
4. 标起点但不标终点，点切换，确认提示且不离开；取消起点后应可切换。
5. 右键某段并更换行为，检查仅该段改变，时间/动物/轨道不变；撤销、重做、保存、退出重开再核对。多选时右键更换也只作用于右键的那段。
6. 选择无可用替代行为的动物时应无非法选项；同轨道已有相接/重叠目标行为时应报错并保留所有原段。菜单靠近窗口底部或右侧仍应可操作。
7. 在隔离副本中注入保存失败或准备损坏的下一张 JSON，确认失败提示、留在原视频且标注不丢；禁止在真实数据上制造损坏。保存失败不允许切换，目标打开失败时此前成功保存的内容仍在磁盘。

Windows 原生构建/新手验收、macOS 分发签名/下载启动及第三方分发材料仍沿用原有待办，不能用这两个功能的验证结果替代。
