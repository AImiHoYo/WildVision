# v1.1.3 启动引导热修复

2026-10-22。

## v1.1.3 覆盖修订

启动引导改为“选择软件所在文件夹”，明确先选择软件 ZIP 解压目录、进入样本库后再导入数据集。选错时以醒目的错误提示显示所选完整路径和原因，取消和成功重试会清除错误状态；原有数据保持不变。按维护者要求覆盖 v1.1.3 附件并将标签对齐新源码，旧提交仍保留在 main 历史中。

## 修复内容

v1.1.2 在 macOS 临时隔离路径中运行时直接退出，导致下载解压后需要手动移动 App。v1.1.3 取消这个启动前置失败：窗口正常打开，无法自动确定可写数据目录时显示引导，用户选择包含当前版本程序和 BUILD.json 的解压文件夹后继续进入样本库。取消、选错目录或无法写入时仍停留在引导页，可以重试。

默认记住位置。用户设置 ~/.wildvision/startup-location.json 只记录版本与所选目录，不存储视频、标注或自动保存；这些数据仍在所选便携目录的 datasets/runtime。能够正常定位程序目录时优先使用程序所在目录；否则尝试当前版本已记住且仍有效的目录，无效时重新引导。不勾选记住时不新建位置记录；此前有位置记录则清除旧提示值。记住失败不阻止本次使用，但明确提示下次可能需要重选。

不会移动、合并或删除旧数据，不关闭 macOS 安全机制，不要求终端命令。操作系统第一次打开时的“隐私与安全性”确认仍需用户完成。

## 本地验证及范围

- 14 项前端测试和 TypeScript/Vite 构建通过。
- 后端在隔离副本完整执行 60 项测试并通过。新增 6 项测试覆盖：无法定位时仍返回可渲染引导状态、引导期间禁止导入与自动保存、取消/选错重试、选定当前版本目录、记住后重启、取消记住、旧版本记录失效、只读目录重试、设置保存失败仍可使用。
- 新增构建元数据供冻结应用校验所选目录的版本，拒绝误选旧版本文件夹或 datasets 子目录。
- 发布附件必须额外核对 build-info.json、程序架构、版本、ZIP CRC/SHA-256 和 macOS 签名，以及源码快照一致性。最终原生 CI 和实际界面验证结果见该版本 Release。

路径分支单元测试使用模拟冻结进程参数；不冒充原生 Windows 实机或全新 macOS 下载验收。原生 UI 可以在隔离副本的命名路径中模拟路径随机化触发，若这样操作需明确区分实际系统 Gatekeeper 隔离。模型额度限制下本次未获得新的 GPT-6.1-Sol 完整复核；最终验证由主代理执行。

原始记录在默认忽略的 doc/release/validation/20261022-startup-hotfix/。扬声器听验、原生 Windows 完整运行和既有第三方材料缺项不改记为通过。

## 重复检查步骤

1. 完整解压当前版本，正常可写路径直接进入样本库；核对实际数据路径。
2. 在隔离副本模拟无法定位路径，确认窗口显示“选择软件所在文件夹”，而不是“启动失败”。
3. 点选择，先取消，再选错目录、datasets 子目录、旧版本目录和模拟不可写目录，确认保留引导且无隐式回退。
4. 选择正确的便携根目录，确认进入样本库；导入独立合成数据集，检查视频、JSON 和索引在该目录 datasets 中，自动保存在 runtime 中。
5. 勾选记住后重启，检查仍使用同一位置；移动或删除合成目录、改变版本、破坏位置记录后重启，应回到引导。
6. 不勾选记住时，不新建位置记录，下次无法自动定位时再次引导。设置文件无法写入时本次仍可使用并提示。
