# 双平台新手版发布要求

2026-10-21：用户已明确要求 Windows、macOS 双平台，使用者不懂代码也能打开使用，无需自己安装或配置开发环境。这是发布硬性条件；当前候选版尚未通过，不能用源码运行或开发机测试代替。

## 用户应该经历的流程

- Windows：下载标明系统和架构的 ZIP → 完整解压 → 双击 WildVision.exe → 导入视频/数据集并开始标注。
- macOS：下载标明适用芯片的 ZIP → 解压并将 WildVision.app 拖到 Applications → 启动 → 导入视频/数据集并开始标注。
- 安装/拖动应用是正常使用步骤；不要求用户打开终端、运行脚本、下载源码、安装 Python/Node/Git/Homebrew、执行 pip/npm、设置 PATH 或安装 FFmpeg。
- 所需运行组件必须随 ZIP 提供并由应用自动定位；若必需系统组件需要配置，应由随包图形启动程序自动完成，不能让用户自行安装环境。为确保拿到完整安装包后可离线使用，本轮验收要求断网安装与首次启动也能完成，不依赖在线 bootstrapper。
- 不以关闭安全保护、删除 quarantine、运行管理员命令或手动修复环境作为标准安装流程。

## 交付与平台矩阵

计划分别准备 Windows x64、macOS Apple Silicon arm64、macOS Intel x86_64 候选包；后两者可在完整验证后合并为 universal2。双平台是已确认要求；最低系统版本及具体架构覆盖仍须由构建能力和目标机器实测确定，不能将“macOS”默认等同当前 arm64 开发机。Windows ARM64 如未实测，不作原生支持承诺。

正式发布附件统一为 ZIP，不以 DMG/MSI/裸 EXE/裸 .app 作为下载入口。命名与打包流程见 [ZIP 发布规程](ZIP_Release_Procedure.md)。

每个候选包必须包含版本号、系统/架构标识、SHA-256、简明安装说明、已知限制、第三方声明。GitHub 的 Source code ZIP 不是普通用户的安装包。开发入口 Start_Mac.command / Start_Windows.bat 只给开发者使用，不计为发布交付物。

| Windows WebView2 | 已加入官方离线安装器下载、Microsoft 签名核验、随 EXE 打包与首次启动配置代码；待 Windows 实测 | 安装程序检测并自动部署随包的离线运行时，或使用经 pywebview 实测的随应用固定版本；不能让用户自己找安装器 |

| 裁剪工具 | 已改用锁定的 imageio-ffmpeg，构建收集其二进制，精确重编码保留音轨；待最终包验收 | 随平台包提供经审核的 FFmpeg 二进制与所需库，程序从包内绝对路径调用；保留音轨和错误提示，记录版本与许可证材料 |
| macOS 分发 | 当前 arm64 包为 ad-hoc 签名 | 完成面向用户分发的签名/公证方案与真实下载启动验收；账号/证书未落实时列 blocked |
| Windows 分发 | 未验证最终 ZIP 与 SmartScreen 行为 | 制作完整 ZIP 并验证签名/系统提示、非管理员使用和解压后启动；删除应用与保留用户数据的操作写清楚；签名不保证没有信誉提示，记录实际结果 |
| 用户数据目录 | frozen 应用已改为用户 ~/.wildvision/datasets，自动保存按工作区身份区分；待目标机验收 | 数据和日志写用户可写目录；从 Applications/Program Files 运行、升级或卸载应用不丢标注 |
| 启动失败 | 已加入 macOS/Windows 原生错误提示及日志路径；待 GUI 验收 | 普通用户能看到中文错误窗口和“查看/复制日志”入口，不允许无窗口退出后要求看终端 |

## R15-N 新手验收流程（交给 GPT-6.1-Sol 执行与记录）

准备：每个承诺的平台/架构使用干净机器或还原 VM 快照，记录系统版本。不得预装 Python、Node、Git、FFmpeg 或项目依赖；Windows 另准备缺 WebView2 的受控镜像，不卸载用户当前机器的组件。先从浏览器下载最终候选附件，记录 SHA-256 和系统来源标记，再断网。使用普通用户账号。

1. 按公开的三步以内安装说明完成安装/拖动，不运行命令；缺运行组件时由随包启动程序处理。记录点击步骤、权限提示和错误。
2. 首次打开应用，确认图标、版本、中文界面、离线字体和首次使用提示正常。没有终端窗口、缺 DLL 错误或环境安装指引。
3. 导入合成 MP3/AAC/无音轨视频与含中文、空格的文件夹；播放、暂停、拖动、音量、实际声音和音画同步按 R06/R07 验收。
4. 创建双轨道三段标注，保存、完全退出、再次打开，按 R10 独立比较标注；导出可解码带声裁剪，确认不借用系统 PATH 下的 FFmpeg。
5. 在默认安装目录运行，确认标注、缓存和日志写用户目录；应用目录不可写时仍可工作。
6. 解压新版本并替换应用后再打开旧数据，确认格式兼容、原数据未丢失；卸载只移除程序，用户数据处理有明确说明，不能默默删除。
7. 在受控副本模拟缺资源/启动失败，验证可见错误与日志入口；不得用禁用系统安全检查的方法绕过故障。
8. 让一位未参与开发的人仅凭下载页和快速说明完成首次标注，记录是否需要口头指导或额外安装。

每步记录 pass/fail/blocked/not_run、机器环境、附件哈希、截图和实际结果；实际声音缺听验/录音证据时不得通过。Windows/macOS 各自验收，任何一方未完成，整体双平台发布验收就未完成。
