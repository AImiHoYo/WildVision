# v1.1.4 行为洞察排版验证

2026-10-23。维护者已验证本地 macOS 候选版，并明确同意发布 v1.1.4。

## 变更范围

筛选栏横跨页面；行为时间分布与持续时长卡片并排且等高；活跃度图独占下方一行。玫瑰图随可用空间缩放，折线图按容器实际宽度绘制。较窄窗口改为纵向排列并允许整页滚动。分析提示默认收起，展开后仍可打开各问题说明。

统计数据的汇总算法保持不变，新增空折线数据保护。此次没有修改视频标注、保存、导入或导出逻辑。

## 本地检查

- 前端构建及类型检查通过；现有 14 项前端测试通过。
- 原生 App 构建时执行的 60 项后端测试通过。
- macOS arm64 App 版本为 1.1.4，ad-hoc 签名完整性检查通过。
- 实际 App 检查 1440×900 标准窗口、1100×800 窄窗口和 2560×1351 宽窗口。窄窗口通过滚动条可访问最后一张图表，无须缩小文字。
- 检查浅色/深色主题、玫瑰图/矩阵切换、分析提示展开与问题弹层、筛选清空、手动更新和恢复全选。
- 内置演示样本恢复全选后仍为 17 段、55.0 秒、有效行为占比 84.2%、多轨并发率 33.0%。这些数值仅用于界面回归核对，不是用户数据集的标注结果。

## 发布核对与限制

Windows x64 和 macOS arm64 的最终 ZIP 由对应 GitHub Actions 原生构建；构建、版本、源码提交及附件校验另行核对。

本次未进行 Windows 1.1.4 的真实机器操作验收；跨系统实际声音、最低系统版本，以及此前记录的第三方分发材料缺项，不能由此次排版验证认定为通过。相关记录见 [发布状态](Release_Readiness_Status.md)。macOS 仍使用 ad-hoc 自签名，首次下载打开按 README 的“隐私与安全性”流程操作。
