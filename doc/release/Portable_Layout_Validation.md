# v1.1.2 便携目录验证

2026-10-22。ZIP 包含已提交源码的目录结构、独立桌面程序、datasets 和 runtime。源码只是随包提供，普通用户不需要安装开发环境。

## 行为

- 发布版从 sys.executable 定位程序：Windows 使用 EXE 所在目录，macOS 使用 .app 外层目录；不依赖当前工作目录或 PyInstaller 临时解包路径。
- 导入数据写入同级 datasets；自动保存与启动日志写入 runtime。路径不可写时提示，不回退到隐藏用户目录。旧版数据保留，不自动迁移、合并或删除。
- 样本库显示实际数据目录，并提供打开目录的按钮。导入后的 videos、annotations、dataset_index.json 均位于数据集子目录。
- 搬动整个文件夹后，索引会重新绑定当前位置；已保存的 JSON 不变。便携数据集的自动保存使用相对身份，并记录可重定位的工作区。
- macOS 在已知的 AppTranslocation 路径中运行时提示退出并用 Finder 移动 app 后重开。路径识别依赖当前系统实现，不能承诺所有 macOS 版本的下载放行行为；不禁用 Gatekeeper 或清除隔离属性。

## 验证及边界

本地前端 14 项测试、TypeScript/Vite 构建通过。后端在隔离副本完整执行，新增针对性测试覆盖 Windows/Mac 路径、临时路径隔离、不可写无回退、工作区搬家、自动保存身份、Git 快照排除未跟踪数据和拒绝凭证文件。路径分支使用模拟的冻结进程参数，不冒充 Windows 实机测试。

GPT-6.1-Sol 独立执行了首批 6 项针对性测试，并补做搬家后的自动保存恢复；其复核发现快照应额外拒绝被强制跟踪的 .env。主代理补上拒绝规则及合成回归测试。代理随后因模型额度结束，最终新增防线由主代理验证，不记作代理完整复核。

源码通过 Git 实际忽略规则及基础敏感内容扫描。包装只取 git archive 的已提交文件，拒绝未提交的跟踪文件和常见凭据、媒体、依赖/运行数据路径；不复制本机 datasets、runtime、node_modules、.git 或原始验证记录。此为基础检查，不代替完整安全审计。

原始记录保存在默认忽略的 doc/release/validation/20261022-portable-layout/。最终包检查与 CI 结果以 GitHub 对应版本发布说明为准。原生 Windows 完整运行、扬声器听验、全新 macOS 下载后的 Gatekeeper 验收及既有第三方分发材料缺项未改记为通过。

## 重复验证

1. 完整解压对应系统 ZIP，检查程序与 datasets 同级，源码目录存在，初始 datasets 只有说明文件，无真实视频。
2. 在隔离目录导入合成数据集，检查 videos、annotations、dataset_index.json 的物理位置；点“打开数据文件夹”，核对实际打开的位置。
3. 保存一段标注，退出，记录 JSON 哈希；把整个便携文件夹移到包含空格的新目录，重新打开同一数据集，确认视频和标注可读、标注 JSON 哈希不变，再保存一次。
4. 对合成未保存修改执行自动保存，搬家后从空白会话恢复，确认工作区指向新目录、恢复为待保存状态且能写入正式标注。
5. 用模拟只读异常验证明确失败而不回退；在实际只读卷上的完整桌面运行另行记录，不用管理员身份绕过后声称通过。
6. 更新时在新目录解压，再复制旧 datasets/runtime，避免覆盖旧数据。旧隐藏目录的数据仅复制；保留原件。
