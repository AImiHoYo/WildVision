# v1.1.1 播放倍速与首次打开说明

2026-10-22。

## 使用方式

视频下方的播放栏增加倍速按钮，默认显示 `1×`。点击后可选 `0.25×`、`0.5×`、`1×`、`1.5×`、`2×`、`3×`，也可以输入自定义数字，再点“应用”或按回车。零、负数、空值不能应用；如果播放组件不支持某个数值，会提示并保留原倍速。

播放中也能调整倍速。画面和分离音轨使用相同倍速；在本次打开的软件里切换视频会保留选择，重新启动软件默认回到 `1×`。倍速不改变视频帧率、标注区间或导出文件的源时间，25 fps 下“下一帧”仍前进 0.04 秒。

README 增加了 macOS “Apple 无法验证 WildVision.app”弹窗示例与处理步骤：先点“完成”，再到“系统设置 → 隐私与安全性”找到 WildVision 的提示，选择“仍要打开”并按系统要求确认。仍采用维护者已确认的 ad-hoc 自签名方案。

## 已执行验证

- 主代理完成前端 TypeScript/Vite 构建，14 项前端测试通过。GPT-6.1-Sol 独立重跑 14 项测试，并补充验证音轨默认倍速属性抛错时，画面与音轨的两个倍速属性全部回滚，源时间不变；未发现可行动缺陷。
- 主代理使用隔离的合成视频、真实 Python `BackendAPI` 和 React 生产界面，在本机 Chrome 通过实际按钮和键盘操作验证。测试页面只读取媒体属性记录结果，没有用脚本代替用户点击或预设媒体时间。
- 六个预设均在真实媒体元素中观测到对应倍速；自定义 `1.25` 生效，`0` 显示无效值提示，浏览器不支持的 `100` 显示提示并保留原来的 `1.25`。
- AAC 内嵌音轨和 MP3-in-MP4 分离音轨两条路径均有覆盖。分离音轨播放时，画面静音、独立音轨启用，两者同步变速、暂停；本次观测的 54 个播放样本中最大时差约 0.054 秒。时钟测量的中位值分别约为 1.248、1.992、0.518，分别对应选择的 1.25、2、0.5 倍；不是声卡输出或扬声器听验结果。
- 播放中从 2 倍改为 0.5 倍未自动暂停；前后切换视频后保留自定义 1.25 倍。原有 0.5–2.5 秒标注保持不变，25 fps 下一帧仍前进 0.04 秒。自定义输入框中按方向键没有触发逐帧，Esc 可关闭面板。
- 隔离源码构建执行 47 项后端测试并通过，生成 v1.1.1 macOS arm64 候选 ZIP。包装流程校验版本、架构、签名完整性、ZIP CRC，并生成 SHA-256。

原始记录保存在默认忽略的 `doc/release/validation/20261022-playback-speed/`，未提交合成视频、临时工作区或本机路径。

## 验证边界

上述实际交互使用本地测试适配器中的真实后端，不等同最终 Windows EXE 或 macOS WebView 的全部验收。未重新做扬声器听验、干净系统安装、CrossOver 补装 .NET 后复测，亦未把这些项目记为通过。极端自定义倍速的支持范围和是否保留声音取决于播放组件；不承诺所有正数都可用。

第三方分发材料的既有缺项继续见根目录 `THIRD_PARTY_NOTICES.md`。本次只新增播放控制、文档和版本，不宣称已补齐这些材料。

## 重复验证步骤

1. 用至少两段合成视频导入独立测试数据集，包含一段 AAC-in-MP4 和一段 MP3-in-MP4；不要使用真实标注做破坏性试验。
2. 逐一选六档倍速，确认菜单显示和实际画面速度；输入 1.25，分别测试“应用”与回车。
3. 输入 0、负数、空值和播放组件不支持的值，确认提示且旧倍速继续生效。输入框方向键、回车与 Esc 不应触发标注快捷键。
4. 播放中改变倍速，检查画面与声音同步、暂停和恢复；切换视频、返回样本库再打开视频，检查当前会话的倍速保留。
5. 在非 1 倍下逐帧并新增一段，核对保存与导出的时间仍是原视频时间。关闭重开，确认标注保留；倍速默认恢复 1 倍。
