# 行为与动物名称的悬停对照

时间轴轨道、行为列表、已标区间、视频左上角浮层和物种筛选支持悬停查看完整英文名称。已收录中文时同时显示中文；键盘聚焦可操作的标签也会显示提示。提示框支持换行，较长列表可以滚动查看；按 Escape、点击或开始拖动即可收起。

中文只用于阅读提示。标注文件、类别匹配、轨道和导出仍使用原始英文，不会因补充翻译而改变。

## 索引与当前覆盖

索引位于 `ui/src/data/labelCatalog.json`，随前端打包，离线可用。行为与动物分别以完整英文原文为键，来自 AR 表的 `list_animal_action` 和 `list_animal`。前者是“动物、行为”配对列表，提取配对中的行为；部分单元格还嵌套了字符串列表，提取工具会展开后再去重。

- 行为：140 个键，已依据工作簿 Action 表定义整理中文释义。它们是辅助理解的译文，不是数据集官方中文标签，也未经过领域专家逐项审校。
- 动物：899 个原始名称，当前收录 718 个中文对照，其余 181 个保留待核对状态。名称中包含泛称、幼体和同义写法，不能将键数当成独立物种数。
- `Gallinago Gallinago Bird` 和 `Common Snipe` 对照为“扇尾沙锥”，学名 `Gallinago gallinago`，依据[生态环境部《中国生物多样性红色名录——脊椎动物卷（2020）》](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202305/W020230522536559098623.pdf)；`Duck` 保持为“鸭（泛称）”，不推断具体鸭种。
- 原始键 `��ommon Eider` 含乱码，标为 `needs_review`，不自动替换或指认为其他物种。

已对未翻译名称逐项检索 [GBIF 分类名录](https://www.gbif.org/)和 [iNaturalist](https://www.inaturalist.org/)。已采用的名称保留逐条来源、核对日期、可确认的学名与分类等级。物种名称需匹配学名或明确的英文名，并核对动物大类；不能采用搜索列表的第一项。属、科等泛称保留较高分类层级，不推断种级身份。普通词的泛称释义单独标明，引用双语名称资料，避免将其当作视频中个体的鉴定结果。

例如，`Viper` 不会因为其他语言的同名结果而译成鸟类；`Blackbird` 在不同地区有不同指代，保留待核对说明；`Aphis Fabae Alates` 保留“有翅型”。剩余项目及检索入口见 [尚待核对的动物名称](Animal_Translation_Pending.md)。检索不到可确认的名称不表示它不存在中文名；这批对照仍可依据新证据继续修订，不作为正式分类鉴定。

`Attending` 按原定义译为“定向关注”，不是“照料”；`Sensing` 译为“感知周围”，并提示注意力未固定于单一刺激。`Escaping` 与 `Fleeing` 分别表示被抓住后挣脱和未被抓住时逃离。原始定义有重叠的类别（如 `Grooming`、`Preening`）保留英文和区分说明，不合并类别。

## 补充或更正译名

每条记录保留 `zh`、`status`，可补充 `scientificName`、`source`、`note`。仅 `status: "translated"` 且中文非空时显示译名；`pending` 和 `needs_review` 显示“中文译名待核对”，并显示已确认的学名或歧义说明。不属于索引的新标签显示完整原文及“暂无中文对照”。

物种应先确认学名或明确分类范围，再从可靠名录核对中文名，将证据加入 `sources`。泛称不细化到具体物种；幼体名称和疑似错拼单独核对，不采用模糊匹配或自动删除后缀。行为应对照 Action 表的 Description，而不是只按英文单词翻译。

更新元数据后可运行：

```sh
python3 scripts/extract_label_catalog.py /path/to/metadata.xlsx --output ui/src/data/labelCatalog.json
```

工具只读取工作簿，保留仍存在标签的已有译文、来源与备注。修改索引后需重新构建前端；当前不提供在已打包 App 外直接编辑索引的功能。

元数据来源：[Animal Kingdom 官方仓库](https://github.com/SUTDCV/Animal-Kingdom)。索引只收录类别名称及翻译说明，不包含视频、视频 ID、逐视频标签记录或原始 Excel。
