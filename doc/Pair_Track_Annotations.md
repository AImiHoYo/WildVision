# 动物与行为组合轨道

一条可见时间轴轨道对应一个唯一的 `(animal, action)` 组合。例如 `Flamingo—Walking` 和 `Flamingo—Drinking` 各占一行。重复的原始标签或 `list_animal` 中重复的动物名称不再生成多条相同组合的轨道。

这套标注记录动物类别与行为在视频中的出现时段，不从原始键值对推断个体身份，也不按个体数量累计时长。

- 同一组合可以有多个不连续区间，例如行走在 0–2 秒和 5–7 秒分别出现。
- 同一组合重叠或相接的区间按时间并集合并。例如 0–2 秒和 1–3 秒合成 0–3 秒。
- 不同行为、不同动物的区间独立保存，可以在时间上重叠。
- 右键更换行为后，片段出现在目标组合轨道；若与该组合已有片段重叠或相接则合并，支持撤销与重做。

## JSON 与旧数据

`list_animal_action` 是可选组合清单，不是已经完成的时间标注。`annotations` 的既有存储结构继续按动物分组，每组 `actions` 中可以保存多个行为、多次出现的时间段。界面组合轨道数不等于 `annotations` 外层元素数。

例如同一火烈鸟类别有 7 个行为组合时，界面显示 7 条组合轨道；JSON 仍可只有一个 `animal: "Flamingo"` 分组，其 `actions` 保存全部行为片段。`actions: []` 表示尚无保存的行为时间段。

旧格式的分组索引继续用于读写兼容，不作为个体身份。旧文件中散落在多个动物分组的相同组合会显示在同一条组合轨道；载入后，相同组合的重叠时间段会在内存中合并。读取不会直接重写原文件，保存后才写入当前结果。新旧数据切换前应保留原始文件备份，尤其是此前确实按个体组织的数据。

动物与行为始终使用原始英文保存；悬停中文只帮助阅读，不改变匹配与导出类别。

行为洞察也按组合口径计算：同一视频内，相同组合的重叠区间先取并集再累计时长与片段数；不同组合分别累计。“组合并发率”表示有行为的采样时刻中，同时存在多个组合的比例，沿用现有时间采样估计方法与前景时间分母，不表示多只个体的并发率。

原始任务背景：[Animal Kingdom Action Recognition 官方说明](https://github.com/SUTDCV/Animal-Kingdom/blob/master/Animal_Kingdom/action_recognition/README_action_recognition.md)。组合轨道与时间并集规则是 WildVision 本次确定的补充标注口径，不声称是原始数据集已提供的个体或时间边界真值。
