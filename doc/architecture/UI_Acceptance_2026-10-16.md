## 修改内容

- 前端组件按工作台 `studio/`、数据集 `dataset/`、评测 `evaluation/` 和通用组件 `ui/` 分组，修正全部引用；抽出行为检查器和播放工具栏，将重复的键盘焦点工具合并到 `lib/focusField.ts`。
- 文档增加总入口和当前实现维护说明；保留既有课程分工、数据契约和历史 UI 方案，不代填人员信息或改动评测含义。
- 主题颜色改为统一 CSS 变量，顶部、视频预览、检查器和时间轴采用一致的面板边界、留白、字号及焦点样式。
- 行为条目减少重复边框和徽标，选中状态与行为色分开表达。
- 区间条目重排为身份信息／时间操作两行，修复默认侧栏宽度下名称和输入框挤在一起的问题；保留秒数精度和原有提交回调，数值步进跟随 FPS。
- 播放栏分离时间状态与操作分组，保留主要操作文字，次级操作通过图标、可访问名称和提示说明呈现，减少重复快捷键方框。
- 本地打包 Inter 和 JetBrains Mono 变量字体，不新增运行时字体服务请求；字体许可证和精确来源保存在 `ui/public/fonts/`。
- 时间轴片段使用既有 `getActionColor`，修复所有已标片段被写死为蓝色的问题。没有修改行为色板、时间坐标换算或标注数据结构。
- 修正小窗口面板最小尺寸约束，避免行为列表被完全挤没。窄屏采用上下工作区、检查器内部左右排列；窄屏高度和桌面侧栏宽度独立保存。
- 分隔线支持拖动和方向键，轴向正确，键盘操作不冒泡触发逐帧播放。
- 桌面启动背景改为与浅色主题一致。

# WildVision Studio 原生验收补充

2026-10-17。源码：项目根目录（已移除开发机个人路径）。

原生电脑控制已恢复，现已取得真实 macOS 应用窗口的运行和交互证据。此前“权限／连接阻塞，原生未验收”的记录已被本次结果更新。最新交付是 `WildVision-macOS-arm64-2026-10-17.zip`；请解压并打开其中的 WildVision.app，已有 release 中的旧应用未覆盖。

## 实际修复

1. `ui/src/bridge.ts`：原生冷启动时，WKWebView 的 API 对象可能先出现，而 `get_state` 方法尚未注册。原实现只等待对象，会在首次进入时显示初始化失败。本次改为等待具体方法可调用，保留十秒超时；已执行的后端操作不会被自动重试。修复后两次新构建冷启动均直接显示后端欢迎信息。
2. `ui/src/lib/playback.ts` 与 `App.tsx`：原生视频在 12 秒末尾点击下一帧，曾出现 `00:12.040 / 00:12.000`。现在将播放定位限制到已加载的视频总时长，并在 ended 事件清除播放状态。最终应用连续快进至末尾并再次下一帧，显示 `00:12.000 / 00:12.000 F0300/0300`。该改动只约束播放头，不改变标注区间、类别或帧换算规则。

## 原生交互证据

测试数据来自独立复制的 sample_dataset，所有新增、编辑、删除、撤销和保存都作用于测试副本。

- 通过原生文件选择器打开数据集，进入 AAACXZTV 工作台。
- 在首次桥接修复构建中创建第一轨 Attending 0–1 秒，编辑终点为 1.2 秒，删除后撤销；第二轨创建 Eating 3–4 秒，并保存。
- 最终构建重新载入后，两个区间、行为和轨道正确恢复；再次按 ⌘S，原生状态显示“已保存…（2 段）”。独立读取 JSON 确认秒数、帧数和轨道对应正确。
- 播放／暂停、末尾快进与下一帧、未标筛选的空状态、返回全部行为均验证。
- 三处分隔线实际拖动：侧栏宽 360→400，区间区高 260→230，时间轴高 224→244；重置菜单恢复 360／260／224。
